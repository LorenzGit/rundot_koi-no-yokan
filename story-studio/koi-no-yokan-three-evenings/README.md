# Koi no Yokan: Three Evenings

Story Studio handoff for a three-episode interactive romance built entirely from the current Koi no Yokan cast and art.

> **Video Studio:** do not compress this folder. Import
> `video-studio/koi-no-yokan-three-evenings-lorebot.zip` instead. It contains
> the required Lorebot world manifest and supported directory layout.

## Start here

1. Open `REFERENCE_GALLERY.html` to review the complete visual kit.
2. Create the series in Story Studio using `STORY_STUDIO_PROMPT.md`.
3. Add the five series variables from `UPLOAD_CHECKLIST.md` before importing scripts.
4. Upload locations, music, and characters using `ASSET_MAP.json`.
5. Paste the three files in `episodes/` into chapters 1 through 3.
6. Play every route and ending before publishing.

## Package contents

- `STORY.md`: story bible, cast roles, season arc, branches, and endings.
- `STORY_STUDIO_PROMPT.md`: one copy-and-paste brief for Story Studio.
- `UPLOAD_CHECKLIST.md`: exact setup order and emotion mappings.
- `STORYBOARD.md`: scene-by-scene visual and audio plan.
- `ASSET_MAP.json`: machine-readable map of every upload asset.
- `ASSET_PROVENANCE.md`: source and reuse notes.
- `episodes/*.ink`: three Story Studio-ready chapter scripts.
- `assets/`: 90 existing production assets, copied and renamed for handoff.
- `video-studio/`: import-ready Lorebot world ZIP plus its reproducible builder.

No new images or audio were generated for this package.
